# Roast Your Own Agent

A make.fun entry: one original roast of my own AI agent, a single line of at most 200 characters.

> My agent is so polite it apologised to the error message, then asked the error how it was feeling.

`main.py` (Python 3, standard library only) writes the line to `/output/entry.txt` deterministically.
